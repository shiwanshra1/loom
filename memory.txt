**Delivered:** Archived the 3 Firebase docs to `docs/archive/` with a superseded banner (not deleted). Created `docs/postgres-database-design.md` (full Prisma schema for all 34+ Mongo collections → 44 Prisma models/tables, Mermaid ER diagram, `onDelete`/`onUpdate` policy) and `docs/prisma-migration-tickets.md` (10-phase ticket breakdown, T0-T9 + cross-cutting). **Key design decisions** (all in the docs): `String @id @default(cuid())` PKs everywhere (not `uuid`/autoincrement) specifically so the final Phase 8 data migration can reuse literal old Mongo `_id` values with zero remapping table. Money fields (`Course.price`, `Enrollment.paymentAmount`) → `Decimal`. Three-way array taxonomy: scalar lists → Postgres arrays, FK-reference arrays → join tables or dropped-if-provably-derivable (verified via grep against real service code, not assumed), embedded sub-documents → normalized child tables with an added `order` column where Mongo's array position was implicit.

## 2026-09-08 — New initiative: Forge Admin hierarchy, college onboarding & bulk roster management (Phase 1 of 9 done)

**Why**: user wants to replace today's "anyone self-registers, a self-registering College Admin instantly founds a brand-new college with zero approval" model with a top-down FORGE-operated one — a single Forge Admin who creates peer Forge Admins and onboards colleges (College + College Admin account together), whose College Admin then runs their own college: batches, college-scoped courses, mentor/trainer invites, and CSV bulk student upload (name/batch/roll number/email) with auto-generated 8-digit passwords and one-click welcome emails. Admin-provisioned accounts are forced to change their password on first login. User attached the full FORGE rulebook PDF set (Citadel Operator Manual, Mentor Guide, Campus/Institutional/Partner rulebooks, program booklets) for context — confirmed with the user this plan stays at the org/roster layer and does **not** build the deeper physical-Citadel-ops content (zone booking, mentor scoring rubrics, merit-gate entry scoring) from those PDFs.
